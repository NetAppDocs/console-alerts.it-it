= Visualizza i dettagli degli avvisi per il tuo sistema storage ONTAP in NetApp Console
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Visualizza gli avvisi associati al tuo sistema di archiviazione ONTAP e approfondisci i dettagli.



[[view-alert-details]]
== Visualizza i dettagli dell'avviso

. link:alerts-start-login.html["Accedi alla NetApp Console"] .
. Dalla barra di navigazione sinistra della Console, seleziona *Archiviazione* > *Avvisi*.
. Dalla pagina Elenco avvisi, seleziona un avviso.
+
image:alerts-detail.png["Dettagli dell'avviso"]

. Scorri verso il basso per trovare le azioni correttive suggerite.
. Scorri verso il basso per trovare altri avvisi correlati all'oggetto per cui è stato generato l'avviso.




[[view-details-about-the-cluster-in-ontap-system-manager]]
== Visualizza i dettagli sul cluster in ONTAP System Manager

. Dalla pagina Elenco avvisi, seleziona un avviso.
. Dall'avviso, seleziona il nome del cluster nella parte superiore della pagina.
+
ONTAP System Manager ora mostra informazioni sul cluster.
